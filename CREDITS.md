# Credits

Everything used to make Wild City PH, and where it came from.

## Built with

- **Arc Studio** (https://studio.arc.io): built the game, the smart contracts on Arc Testnet and the first deployment

## Characters

| What | Source | Licence |
|---|---|---|
| Ada (main character) | Adobe Mixamo character "Ch03": https://www.mixamo.com | Mixamo terms: free, royalty-free use in games |
| Ada's animations: idle, walk, run, jump, sit, talk | Adobe Mixamo: https://www.mixamo.com | Mixamo terms |
| Townspeople: Business_Female_01, Female_Party_02, Sports_Female_02, Male_Adult_12, Male_Adult_18, Male_Adult_04 (`public/models/npc_*_1-3.glb`) | Microsoft Rocketbox avatar library: https://github.com/microsoft/Microsoft-Rocketbox | MIT |
| Townspeople animations: idle, walk, talk with gestures, sitting | Microsoft Rocketbox animations: https://github.com/microsoft/Microsoft-Rocketbox | MIT |
| Simple fallback humans (`npc_female.glb`, `npc_male.glb`, `npc_child.glb`) | Generated by Arc Studio (`src/game/humanoid.ts`) | Part of this project |

Skin tones on some Rocketbox characters were adjusted, and the models were converted to compressed GLB files for the web.

## World

The city, roads, market stalls, zinc sheds, umbrellas, food (akara, suya, jollof, dodo, pepper soup, chin chin), goods (garri, tomatoes, oranges, yam, plantain and more), okadas, kekes, buses and cars are all built in code with three.js. No downloaded models or images.
